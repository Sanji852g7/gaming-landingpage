# Gaming Landing Page

A modern gaming inspired landing page built using React, Tailwind CSS and GSAP.

This project was mainly focused on improving my frontend skills and learning how modern animated websites are structured. A lot of the design and animation style was inspired by cinematic and award style landing pages.

## Live Demo

https://gaming-landingpage-gsap.netlify.app/

## Features

- Responsive layout
- GSAP animations
- ScrollTrigger animations
- Video transitions
- Clip path animations
- Interactive hover effects
- Reusable React components
- Tailwind CSS styling

## What I Learned

This was my first time properly using GSAP and ScrollTrigger, so a big part of this project was learning how animations work together with React components and page scrolling.

Some of the things I learned while building this project:

- Creating reusable React components
- Managing component structure and layout
- Using Tailwind CSS for responsive design
- Working with absolute positioning and z-index layering
- Building scroll based animations with GSAP
- Using clip-path animations
- Handling responsive layouts for smaller screens
- Improving debugging and problem solving
- Working with Git and meaningful commits
- Structuring a larger frontend project properly
